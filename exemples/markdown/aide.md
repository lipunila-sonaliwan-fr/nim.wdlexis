# Aide de l'application

Bienvenue dans **Carnet**. Ce texte est chargé depuis `aide.md` et s'adapte à la largeur de la fenêtre.

## Démarrer
1. Ouvrez un fichier avec *Fichier > Ouvrir*.
2. Modifiez les lignes dans la grille.
   - les colonnes se trient d'un clic
   - les totaux se calculent seuls
3. Enregistrez.

> Astuce : Cmd/Ctrl+C copie ce texte.

```
ui = paquet("interface")
aide = fen:ajouter(ui.markdown{fichier = "aide.md"})
```

Plus d'informations sur [le site du projet](https://sonaliwan.fr).

## Raccourcis
- `Ctrl+N` nouveau
- `Ctrl+S` enregistrer
- `Ctrl+F` rechercher
