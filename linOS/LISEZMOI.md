Bonjour, ami linuxien,

Les distributions Linux sont nombreuses et présentent parfois des différences importantes. Les bibliothèques fournies dans ce dossier correspondent à celles du système d'exploitation Fedora Workstation 44 (ou équivalent), disponible sur le site officiel de Fedora :

<a href="https://fedoraproject.org/workstation/download/" target="_blank" rel="noopener noreferrer">Fedora Workstation 44</a>

En cas d'incompatibilité, notamment en raison d'une version différente de la glibc (glibc-2.43-9.fc44), nous vous invitons à collecter les bibliothèques portant les mêmes noms que celles présentes dans ce dossier à partir de votre propre distribution Linux, puis à les placer dans le répertoire <code>linOS</code>.

Veuillez nous excuser pour cette contrainte. Il ne nous est malheureusement pas possible de tester l'application sur l'ensemble des distributions Linux existantes : AlmaLinux, Arch Linux, Debian, Fedora (autres versions), Kali Linux, Manjaro, Linux Mint, openSUSE, Pop!_OS, Red Hat Enterprise Linux, Rocky Linux, Tails, Ubuntu (y compris Ubuntu Server), Zorin OS, etc.
